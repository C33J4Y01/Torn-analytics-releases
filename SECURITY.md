# Security Policy

## Supported release

Only the latest version of `torn-analytics.user.js` on the `main` branch is supported.

## Release controls

- Releases are promoted manually from a private development repository.
- Development tests and protected security/compatibility invariants must pass before promotion.
- Experimental branches are never used as TornPDA update sources.
- The stable filename and update URL remain unchanged.
- No credentials, Torn logs, exports, account information, or recovery keys belong in this repository.

## Reporting a vulnerability

Do not publish API keys, Torn history, exports, or exploit details in a public issue. Contact the repository owner privately through GitHub before sharing sensitive technical details.
